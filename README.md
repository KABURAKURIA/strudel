# Strudel Music Coding Guides

This repository contains comprehensive guides and examples for using **Strudel**, the live coding environment for music based on TidalCycles.

## Guides

### Learning Path
1.  **[Beginner's Guide](guides/01-beginners.md)**
    *   Basics of syntax, playing sounds, and simple patterns.
2.  **[Intermediate: Rhythms & Layers](guides/02-intermediate-rhythms.md)**
    *   Euclidean rhythms, layering with `stack`, and audio effects.
3.  **[Intermediate: Melody & Harmony](guides/02-intermediate-melody-harmony.md)**
    *   Scales, chords, arpeggios, and transposition.

### Lofi & Nujabes Masterclass
4.  **[Masterclass: Nujabes / Lo-Fi](guides/03-nujabes-lofi.md)**
    *   A deep dive into Jazz chords, humanized rhythms, and texture, featuring 3 full original compositions.
5.  **[Lofi Recipes Cookbook](guides/03b-nujabes-lofi-recipes.md)**
    *   Instant code blocks for Drum Kits (Boom Bap, Dilla), Chord Packs (Neo-Soul, Jazz), and Texture Chains.
6.  **[Creating Infinite Study Beats](guides/03c-lofi-study-beats.md)**
    *   Techniques for creating evolving, endless loops for focus and relaxation.

### Advanced Topics
8.  **[Sampling Deep Dive](guides/08-sampling-deep-dive.md)**

## How to Use

These guides are written in Markdown. You can read them directly on GitHub or in any Markdown viewer. The code examples can be copied and pasted directly into [strudel.cc](https://strudel.cc) or your own Kunguru Algo instance.
