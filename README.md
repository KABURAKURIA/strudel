# Strudel Music Coding Guides

This repository contains comprehensive guides and examples for using **Strudel**, the live coding environment for music based on TidalCycles.

## Guides

### Learning Path
1.  **[Beginner's Guide](guides/01-beginners.md)**
    *   Basics of syntax, playing sounds, and simple patterns.
2.  **[Intermediate: Rhythms & Layers](guides/02-intermediate-rhythms.md)**
    *   Euclidean rhythms, layering with `stack`, and audio effects.
3.  **[Advanced Masterclass: Nujabes / Lo-Fi](guides/03-nujabes-lofi.md)**
    *   A deep dive into Jazz chords, humanized rhythms, and texture, featuring 3 full original compositions.
4.  **[Kunguru Algo Setup (Google Colab)](guides/04-google-colab.md)**
    *   How to set up a full, persistent, and branded "Kunguru Algo" instance in Google Colab Free Tier using Cloudflare Tunnels.

### Deep Dives
8.  **[Sampling Deep Dive](guides/08-sampling-deep-dive.md)**
    *   Mastering `chop`, `slice`, `splice`, and granular synthesis.
9.  **[Advanced Generative Music](guides/09-advanced-generative.md)**
    *   Creating endless, evolving music with `randcat`, probability, and shuffling.

### Song Collections
5.  **[100 Famous Songs](guides/05-100-famous-songs.md)**
    *   A massive collection of code snippets for famous melodies and songs.
6.  **[100 Famous Kenyan Songs](guides/06-100-famous-kenyan-songs.md)**
    *   Arrangements of popular Kenyan music.
7.  **[50 Famous Jazz Songs](guides/07-50-famous-jazz-songs.md)**
    *   Standards and classics in the Jazz repertoire.
10. **[100 More Famous Kenyan Songs](guides/10-100-more-famous-kenyan-songs.md)**
    *   Another 100 arrangements covering Kapuka, Genge, Gengetone, and modern Afro-Pop.

## Examples

## How to Use

These guides are written in Markdown. You can read them directly on GitHub or in any Markdown viewer. The code examples can be copied and pasted directly into [strudel.cc](https://strudel.cc).
